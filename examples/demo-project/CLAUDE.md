## Overview

Estimates the slope and offset of a linear response from noisy single-shot measurements, and quantifies how the estimate degrades with measurement noise. One output: a short methods note. The boundary to a real project is that the "measurement" here is a synthetic generator with known ground truth (slope 2.5, offset 0.8), which is why the recovered values can be checked against the truth rather than against a reference method.

## Data and code

All data are generated, nothing is read from outside the folder. Three files in `analysis/`, following the workspace reproducibility rule:

| File | Role |
|---|---|
| `generate.py` | produces the intermediates: 5 seeds × 3 noise levels, one `.npz` per unit, written atomically and skipped if present |
| `evaluate.py` | every figure and every reported number from those intermediates; writes `Output.txt` with the manuscript location of each |
| `helpers.py` | configuration, fit, metric, atomic write |

## Reproduction

```
cd analysis
python generate.py     # ~1 s here; the expensive half in a real project
python evaluate.py     # → Output.txt + results/figure_1.png
```

`evaluate.py` contains a self-check: it recomputes a stored metric from the stored raw arrays and reports the deviation (currently 0.00e+00). A non-zero value means the two scripts have drifted apart in format.

## Current results

Mean ± std over 5 seeds, test split (30 % held out). Ground truth: slope 2.5, offset 0.8.

| Noise | Slope | Offset | Test R² |
|---|---|---|---|
| 0.00 | 2.5000 ± 0.0000 | 0.8000 ± 0.0000 | 1.0000 ± 0.0000 |
| 0.02 | 2.5004 ± 0.0012 | 0.8000 ± 0.0014 | 0.9992 ± 0.0001 |
| 0.05 | 2.5009 ± 0.0029 | 0.7999 ± 0.0036 | 0.9951 ± 0.0006 |

**Finding:** the estimator stays unbiased across the tested range; both parameters recover the truth within one seed-to-seed standard deviation at every noise level. The cost of noise shows up as spread, not as offset: the std of the slope grows roughly linearly with the noise level, while the mean does not move. R² drops by 0.0049 from clean to the worst level.

**Interpretation, graded:** the unbiasedness is expected for a least-squares fit of a correctly specified linear model and is a sanity check, not a result. What the numbers do establish is the noise budget: at 5 % noise the slope is still determined to about 0.1 %, so a measurement campaign at that noise level is adequate for the intended use. Whether that holds for a misspecified model is untested.
